# Agent Pack — LLM Foundation Models Masterclass

Este paquete es la especificación ejecutable para construir una masterclass de 60 minutos acompañada de un repositorio GitHub, notebooks, demos y Learning RAG.

## Archivos

- `SUPERPROMPT_NINJA_WARRIOR.md`: prompt completo para dar al agente constructor.
- `MASTERCLASS_SPEC.md`: especificación canónica, útil como documento de referencia durante la implementación.
- `SOURCE_REGISTER.md`: registro de fuentes y política de actualización.

## Orden recomendado

1. Dar `SUPERPROMPT_NINJA_WARRIOR.md` al agente.
2. Adjuntar/pegar `MASTERCLASS_SPEC.md` como especificación canónica.
3. Adjuntar `SOURCE_REGISTER.md` como registro de fuentes.
4. Exigir que el agente mantenga la duración núcleo en 60 min y construya los artefactos listados en Definition of Done.

## Principio de producto

La entrega es una experiencia docente reproducible, no sólo un deck.

`slides + experiments + notebooks + RAG + docs + evaluation`
