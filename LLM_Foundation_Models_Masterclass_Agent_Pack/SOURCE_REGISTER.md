## Regla de citas
Toda afirmación factual que pueda cambiar con el tiempo debe registrar proveedor, URL y fecha de consulta. Los números de benchmark no deben aparecer en las slides salvo que sean necesarios y estén contextualizados.

## Observación de actualidad
El catálogo de modelos cambia rápidamente. Google, por ejemplo, mantiene una página de deprecaciones separada y distingue modelos estables, preview y otros estados; por tanto, el proyecto debe tratar nombres/versiones como datos vivos. El RAG es la capa adecuada para mantener esta información actualizada sin sobrecargar el deck.
